This interactive self-portrait explores the shifting space between daily routines and dreamlike imagination. Through mouse interaction, viewers move between different emotional states represented by changing expressions, colour palettes, and symbolic objects. Warm daylight imagery references productivity and everyday habits, while darker dream-inspired scenes suggest reflection, memory, and possibility.
The work combines illustration, animation, typography, and creative coding to create a responsive digital portrait. By navigating the space, viewers actively construct different versions of the self, revealing the fluid relationship between reality and imagination.
Created using p5.js, custom illustrations, and animated visual elements. AI tools were used for concept development, code debugging, and design refinement. All final creative decisions, coding implementation, visual composition, and project development were completed by the author.
